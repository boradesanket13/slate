# Slate

Slate is a browser-based studio that turns **code snippets** and **screenshots** into polished, shareable images. 

Built by [Sanket Borade](https://github.com/boradesanket13). Licensed under Apache-2.0.

## Run it locally

Requires **Node.js 22.17+**.

```powershell
git clone https://github.com/boradesanket13/slate.git
cd slate
npm install
npm run dev
```
